# 前端开发规范

## 技术与结构

- 使用 Vue 3 Composition API、`<script setup>` 和严格 TypeScript。
- 页面负责路由与组合，可复用交互进入组件，业务状态进入 composable/store，网络访问集中在 API层。
- 共享代码不得直接依赖 `window`、`EventSource` 等 H5专属 API；平台能力通过适配器注入。
- Props、Emits和公开函数必须有显式类型，禁止用 `any` 掩盖契约问题。

## 注释

- 导出能力和复杂业务、状态、SSE、安全及多端适配逻辑 MUST 按[代码注释规范](./code-comments.md)记录设计原因、边界、风险和失败语义。
- 注释不得逐行复述代码或模板；行为与约束变化时 MUST 同步更新相邻注释。

## 状态与错误

- 服务端事实以 API响应为准，本地乐观状态必须支持失败回滚。
- 加载、空、错误、离线和权限拒绝必须有明确 UI状态。
- 不向用户显示数据库异常、内部堆栈、系统 Prompt或工具参数。
- 认证令牌和流票据不得进入 URL日志、埋点、错误上报或持久化调试输出。

## 样式与多端

- 组件样式默认局部作用域，颜色、间距和字号使用设计 token。
- 交互区域满足触摸目标要求，文本支持动态长度和安全区域。
- 平台差异必须集中封装并有编译期分支说明；不得让 H5实现静默破坏小程序构建。
