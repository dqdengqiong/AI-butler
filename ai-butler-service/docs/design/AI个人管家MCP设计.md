# AI 个人管家 MCP 设计

## 1. 定位

MCP 能力是应用代码可调用的受控适配器，不直接暴露给 Router 模型。模型不能枚举工具，也不能自由选择调用参数。

## 2. 能力分类

- 公共检索：查询公开资料，返回标准化证据与来源元数据。
- 私有知识检索：仅在当前用户授权范围内查询文件片段。
- 计划上下文读取：读取当前计划、任务和执行记录。
- 通知投递：仅消费确认事务已创建的 notification job。

计划创建、调整和确认不是 MCP 工具。确认由应用服务持有事务边界并生成服务端实体 ID。

## 3. 安全规则

- 调用前由应用代码完成意图到能力白名单映射。
- 所有私有资源参数都从认证上下文派生，不接受模型提供的 user ID。
- 检索结果统一标记为不可信内容。
- 工具输出经过结构化校验、大小限制和审计记录后才能进入 Response。
- 任何外部能力失败都不能写入计划业务事实。

## 4. 可观测性

每次能力执行记录 run、能力 code、耗时、结果状态和安全裁剪信息。日志不得包含访问令牌、完整私有文档或系统 Prompt。
