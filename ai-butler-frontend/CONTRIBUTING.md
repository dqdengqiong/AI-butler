# 贡献指南

- 默认分支为 `main`，提交遵循 `type(scope): description` 形式的 Conventional Commits。
- 每个变更必须通过格式、lint、vue-tsc、单元测试和目标构建。
- API变更必须记录后端契约标签与 commit SHA，生成目录禁止手改。
- UI变更必须验证 H5；涉及平台 API时同时验证微信小程序构建和降级路径。
- 修复 SSE、状态或鉴权缺陷必须添加回归测试。
- AI参与的变更需说明使用方式、人工复核点、执行检查和未验证项。
- 公共能力与复杂逻辑必须具有符合 `docs/standards/code-comments.md` 的注释，评审时同步检查相邻既有注释是否仍然准确。

完成标准：行为满足验收、错误状态可见、无敏感日志、测试通过、文档与契约同步，复杂实现的设计原因、边界条件、副作用与失败语义已有必要注释。
