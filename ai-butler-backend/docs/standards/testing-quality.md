# 测试与质量规范

## 测试层次

- 单元测试不得访问网络，模型使用确定性 Fake，时间和随机数可注入。
- 集成测试使用独立 PostgreSQL、LangGraph和按需 Qdrant测试库。
- 契约测试验证 OpenAPI可重复生成、错误信封和前端生成输入稳定。
- 恢复测试覆盖 Worker崩溃、lease过期、checkpoint恢复、SSE断线和幂等重试。
- 安全测试覆盖越权、Prompt Injection、非法工具参数、日志脱敏和密钥泄露。

## 质量门禁

- MUST 通过格式、Ruff、严格类型检查、pytest、文档链接和密钥扫描。
- 初始化代码的行、语句、函数和分支覆盖率均不得低于80%。
- 修复缺陷 MUST 添加能在修复前失败的回归测试。
- 测试不得依赖执行顺序、真实外部服务或共享生产状态。

## 验证报告

提交或合并请求必须列出执行命令、结果、跳过原因和剩余风险。仅声称实际执行过的检查已通过。
